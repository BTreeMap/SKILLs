# Response-to-Reviewer Mapping

Stage 9 deliverable for the `rebut` verb, alongside the rebuttal draft or
revision letter.

## Input

The user supplies the reviews as text: per reviewer, the quoted concerns and
the score, in any readable layout. Paste them here, one block per reviewer:

- Reviewer <id> (score <n>): <quoted concerns>

## Mapping

| Reviewer | Concern (quoted one-liner) | Class | Response location | Change made |
|----------|----------------------------|-------|-------------------|-------------|
| | | | | |

Classes per the `rebuttal-playbook` triage: misunderstanding, missing
evidence, scope or taste disagreement, reviewer factual error.

## AC-facing summary

Per-reviewer score trajectory and what changed; every accepted point mapped
to its revision location. The AC reads the whole record, so this table is
the deliverable of last resort.
