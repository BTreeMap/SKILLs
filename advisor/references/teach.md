# Verb: teach

Explain one judgment from the four moves to a named audience. When the
audience is unnamed, take student.

| Audience | Calibration |
| --- | --- |
| student | The move as a procedure they run next time, with the artifact's own text as the worked example |
| collaborator | The judgment and its evidence; the procedure is skipped |
| reviewer or funder | The claim, the instrument, the kill test; nothing about the lab's envelope |

Output: the explanation, then one line naming the heuristic behind the
judgment and its full source citation from the tables below. Nothing after
it.

## Heuristics

| Move | Instruction | Source |
| --- | --- | --- |
| Constitution | Ground the work in a conventional combination of prior work and inject one atypical pairing; that mix marks the highest-impact papers | Uzzi |
| Constitution | Generate combinations, including remote ones; a larger and more distant search space raises the odds a valuable one turns up | Simonton |
| Constitution | Check that the work has one clear central idea, not several muddled ones | Levin and Redell |
| Constitution | To survey an area, follow a seed paper's citations and look for shared citations and repeated authors; those are the field's key papers, people, and venues | Keshav |
| Currency | Name how the problem is solved today and where current practice hits its limits | Heilmeier |
| Currency | State what is new in the approach and why it will succeed where prior attempts did not | Heilmeier |
| Currency | Build and deploy the system, measure it, compare it against realistic alternatives, and state its weaknesses | Levin and Redell |
| Envelope | Before calling a problem important, check for a genuine, feasible line of attack; without one, set it aside whatever its prestige | Hamming |
| Envelope | Plot each candidate problem on feasibility against interest and prefer those that score on both | Alon |
| Envelope | Name the risks, the cost, the time, and the mid-term and final tests that show success or failure | Heilmeier |
| Claims | Hold several working hypotheses instead of one favoured explanation | Platt |
| Claims | Design the experiment whose alternative outcomes each exclude a standing hypothesis, and run it first | Platt |
| Claims | Treat every hypothesis as expendable; a clean disproof is progress | Platt |
| Direction | Seek the region where the field's assumptions break down; open problems live there, incremental ones elsewhere | Alon |
| Direction | Keep protected time to ask what the field's important open problems are and how the current work bears on them | Hamming |
| Direction | Ask who benefits and what difference success makes before investing further | Heilmeier |
