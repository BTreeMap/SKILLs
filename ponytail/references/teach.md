# Ponytail Teach Verb

Explain ladder decision so audience can make next one themselves. Prose is
deliverable here, but still no essays.

## Pipeline

1. Name audience (reviewer, teammate, future maintainer); size vocabulary to
   them.
2. State decision as rung arithmetic: what was asked, which rung held, what
   each lower rung would have cost.
3. Give 3am test: what breaks, who gets paged, what reader debugs under each
   alternative.
4. End with trigger that reverses decision, the one a `ponytail:` comment
   would carry.

## Output

Short paragraphs or tight list, sized to audience's question.
