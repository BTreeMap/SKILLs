# The accessibility floor

Owns floor: normative values at precedence 1, which no brand, supplied
document, or instruction overrides. Every value here quoted from
specification.

**Pinned to WCAG 2.2, W3C Recommendation, updated 12 December 2024** (first
published 5 October 2023). WCAG 3.0 is early draft, not Recommendation; do
not apply it. WCAG 2.2 removed SC 4.1.1 Parsing: obsolete, must not be
cited.

**Conformance target is level AA.** AAA criteria marked below as
recommendations. Never present AAA value as required; never present AA value
as optional.

**Re-verify before relying on this file where stakes are legal, contractual,
or regulatory.** Check w3.org/TR/WCAG22; confirm version date still matches
pin. Mismatch: specification wins, this file is wrong.

## Contrast

| Applies to | Minimum | Criterion |
| --- | --- | --- |
| Text below large-text threshold | 4.5:1 | 1.4.3 Contrast (Minimum), AA |
| Large text: 18pt, typically 24px; or 14pt bold, typically 18.66px | 3:1 | 1.4.3 Contrast (Minimum), AA |
| Visual information identifying control or its state | 3:1 | 1.4.11 Non-text Contrast, AA |
| Parts of graphic required to understand content | 3:1 | 1.4.11 Non-text Contrast, AA |

Exempt: inactive or disabled controls; pure decoration; text that is part of
logo or brand name; text that is part of picture containing significant
other visual content; graphics whose particular presentation is essential to
information conveyed.

Divider between two same-elevation surfaces: decoration, exempt; border
identifying where input begins: not. Size is part of measurement: one color
can pass in headline and fail in button label. Measure composited result
wherever transparency involved.

## Target size

| Requirement | Value | Criterion |
| --- | --- | --- |
| Pointer target size | 24 by 24 CSS pixels | 2.5.8 Target Size (Minimum), **AA** |
| Pointer target size, enhanced | 44 by 44 CSS pixels | 2.5.5 Target Size (Enhanced), **AAA** |

24 by 24 is floor; 44 by 44 is recommendation. Brand documentation routinely
confuses the two in both directions. SC 2.5.8 exceptions include sufficient
spacing, equivalent control elsewhere on page, inline targets within
sentence, user-agent-controlled sizing, cases where presentation is
essential.

## Focus

| Requirement | Criterion |
| --- | --- |
| Keyboard focus indicator visible | 2.4.7 Focus Visible, **AA** |
| Focused element not *entirely* covered by author-created content | 2.4.11 Focus Not Obscured (Minimum), **AA** |
| Focused element not covered *at all* | 2.4.12 Focus Not Obscured (Enhanced), **AAA** |
| Focus indicator meets specified size and contrast | 2.4.13 Focus Appearance, **AAA** |

AA floor forbids only total obscuring. Keeping focused control fully clear
of sticky headers, footers, floating panels is AAA behavior: adopt as house
practice, but do not describe it as AA requirement.

## Text and reflow

| Requirement | Value | Criterion |
| --- | --- | --- |
| Text resizes without assistive technology, no loss of content or function | up to 200 percent | 1.4.4 Resize Text, AA |
| No loss of content or function when reader overrides text spacing | line height 1.5x font size; paragraph spacing 2x; letter spacing 0.12x; word spacing 0.16x | 1.4.12 Text Spacing, AA |
| Content appearing on hover or focus is dismissible, hoverable, persistent | | 1.4.13 Content on Hover or Focus, AA |

Captions and images of text excepted from 1.4.4. These three criteria: why
type sizing uses relative units and why layouts must survive reader changing
them.

## Input and flows

| Requirement | Criterion |
| --- | --- |
| Dragging has single-pointer alternative, unless dragging is essential | 2.5.7 Dragging Movements, AA |
| Information already entered in process auto-populated or selectable, not re-entered | 3.3.7 Redundant Entry, **A** |
| No cognitive function test in authentication, unless bypassable or assisted | 3.3.8 Accessible Authentication (Minimum), AA |
| Help mechanisms appear in consistent order across pages | 3.2.6 Consistent Help, **A** |

3.3.8: authentication flow must not break password managers or paste. 3.3.7:
checkout must never ask twice for same address. Both commonly missed because
they read as product decisions.

## Not a standard

Performance targets are vendor's product thresholds, revisable by that
vendor any time, with none of regulatory weight of criteria above.
`platform` owns them. Never present them as standard; never trade criterion
here against one of them.
